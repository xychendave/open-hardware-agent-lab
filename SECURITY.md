# Security and physical-safety reports

Do not file a public issue for vulnerabilities that could enable unauthorized hardware control, bypass an interlock, expose credentials or cause physical injury.

Use GitHub's private vulnerability-reporting flow when it is enabled for this repository. Until then, contact the repository owner privately through their GitHub profile.

For a report, include the affected commit, driver mode, hardware model, minimal reproduction and whether real equipment was involved. Do not repeat a dangerous test on live hardware after the issue is confirmed.

The simulation driver is not a safety-certified controller. Nothing in this repository replaces manufacturer instructions, a physical emergency stop, guarding, risk assessment or qualified on-site supervision.
