# Contributing

This project is in an early architecture and licensing phase.

Issues, reproducible bug reports and design discussions are welcome. Please include:

- hardware model and controller host;
- simulator or real-hardware mode;
- exact command and sanitized output;
- expected and observed safety behavior.

Please contact the maintainer before opening a code pull request. External code contributions are not being accepted until the repository license and contributor terms are decided. This avoids creating ambiguous ownership for a project that may use open-core, dual-license or patent licensing later.

Never include API keys, hardware serial numbers, private camera footage, customer data or unsafe instructions that bypass interlocks.
